# 🌾 سیستم هوشمند مدیریت مجتمع کشت و صنعت (Smart Agri-Management System)

پروژه پایانی درس برنامه‌نویسی پیشرفته (Advanced Programming) - دانشگاه صنعتی شریف.

موضوع شماره ۱۹: سیستم مدیریت مجتمع کشت و صنعت هوشمند

## معرفی سیستم
این اپلیکیشن تصمیم‌گیری مهندسی صنایع بر اساس یک معماری ۴ ماژوله طراحی و پیاده‌سازی شده است:

۱. **ماژول برنامه‌ریزی خطی (LP):** استفاده از کتابخانه `PuLP` برای یافتن الگوی کشت بهینه (گندم، جو، ذرت) و استخراج ارزش‌های سایه‌ای با استفاده از رویکرد تقریب خطی پویا (Dynamic Piecewise Linear).
۲. **ماژول الگوریتم ژنتیک (GA):** طراحی الگوریتم ژنتیک سفارشی با اپراتور OX (Order Crossover) و توقف زودهنگام (Early Stopping) جهت مسیریابی ماشین‌آلات (mTSP).
۳. **رابط کاربری تعاملی (UI):** توسعه‌یافته با `Streamlit` جهت دریافت پارامترها و مصورسازی خروجی‌ها (نمودارهای مسیر، دایره‌ای و همگرایی).
۴. **دستیار هوشمند تحلیلی (LLM):** ادغام با API مدل قدرتمند **Google Gemini** جهت تحلیل نتایج، ارائه دلایل بهینگی و تحلیل حساسیت منابع به صورت پویا (Dynamic RAG).

## 🚀 نحوه اجرای پروژه (Local)

ابتدا مخزن را کلون کرده و پیش‌نیازها را نصب کنید:
```bash
pip install -r requirements.txt
```
سپس یک فایل `.env` در مسیر اصلی ایجاد کرده و کلید API خود را قرار دهید:
```text
GEMINI_API_KEY=your_api_key_here
```
در نهایت برنامه را اجرا کنید:
```bash
streamlit run app.py
```

## 🛠 تکنولوژی‌های استفاده شده
- **زبان برنامه‌نویسی:** Python 3.11
- **هوش مصنوعی:** Google Gemini API (gemini-1.5-flash)
- **بهینه‌سازی ریاضی:** PuLP
- **رابط کاربری و مصورسازی:** Streamlit, Plotly, Matplotlib
- **پردازش داده:** Pandas, NumPy
